# LendingClub Credit Risk Modeling

## Project Overview
This project evaluates credit-risk prediction using LendingClub borrower data combined with macroeconomic indicators. The goal was to compare multiple machine-learning models and assess which factors were most useful for predicting loan default.

## Methods
- Cleaned and transformed borrower-level and macroeconomic data using Python and Pandas
- Merged LendingClub data with Federal Reserve economic indicators
- Built logistic regression, random forest, and XGBoost models
- Used a 60/20/20 train, validation, and test split
- Evaluated performance using classification reports, confusion matrices, ROC-AUC, and feature importance

## Tools
Python, Pandas, Scikit-learn, XGBoost, SHAP, Jupyter Notebook
